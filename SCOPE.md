# Scope

This repo is a personal fork of [mattpocock/skills](https://github.com/mattpocock/skills): the set of skills I use every day, modified to fit my own work. Issues track changes to the skills.

## The bar

A change is worth making when it fixes something that went wrong in a real session: what was run, what the skill did, what was expected. A hypothetical improvement ("it would be better if...") is a weaker reason, though not a disqualifying one in a personal fork.

## By bucket

- **`engineering/`, `productivity/`, `in-progress/`**: the bar above.
- **`misc/`**: kept around, not maintained. See [`frozen-misc-skills.md`](./.out-of-scope/frozen-misc-skills.md).
- **New skills**: if the behaviour composes from existing skills, it does not get a new one. See [`new-skills.md`](./.out-of-scope/new-skills.md).

## Unclear issues

An issue that can't be judged against the bar gets one round of questions and the `needs-info` label. With no reply in 14 days, it is closed. Rejections close as "not planned".
